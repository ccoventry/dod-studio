# Your own upscale styles. Copy this file to my_styles.txt in the game's
# dod\dodstudio_hd folder (next to the style folders),
# uncomment or add lines, then build with:   python build_all.py <name>
# and pick it in game with:                  dodstudio_hd_style <name>
#
# Style names: lowercase letters, digits, - and _ (they become folder names).
# Four kinds of line:
#
#   name = <model>                  an AI upscaling model: put its .param and
#                                   .bin files in realesrgan\models\ and give
#                                   the file name without the extension
#   name = spandrel <model file>    an AI model through the second backend
#                                   (python setup_tools.py --spandrel): the
#                                   .pth or .safetensors file, with its
#                                   extension, in spandrel\models\. That is how
#                                   the newer models on openmodeldb.info run
#                                   (DAT, SPAN, RealPLKSR, HAT, ATD...); 4x only
#   name = plain <sharpening>       no AI: a plain enlargement, sharpened by
#                                   0 (none) to 500 (very strong); plain is 60
#   name = blend <a> <b> <percent>  two styles you've already built, mixed
#                                   file by file, <percent> of <a> (the rest
#                                   is <b>); blend is x4plus plain 50
#
# Examples:

# anime   = realesrgan-x4plus-anime          # comes with Real-ESRGAN
# atd     = spandrel 4xNomos8k_atd_jpg.pth   # from github.com/Phhofm/models releases
# soft    = plain 0                          # just a clean enlargement
# crisp   = plain 150                        # a sharper plain
# sharp70 = blend ultrasharp plain 70        # mostly UltraSharp, calmed down
# gentle  = blend generalv3 remacri 50
